# Security policy

Follow the [Package Broker security policy](https://github.com/package-broker/broker/blob/main/SECURITY.md).

Report security advisories for every Package Broker repository through the broker repository’s [GitHub private vulnerability reporting](https://github.com/package-broker/broker/security/advisories/new) or email [security@package.broker](mailto:security@package.broker). Do not disclose security problems in public issues.

Include the affected repository, version or commit, runtime, steps to reproduce, and the impact you observed.
